1. Цель проекта

Веб-игра, в которой игрок вводит слово, побеждающее предыдущее. ИИ-судья решает, подходит ли слово, подбирает к нему эмодзи и пишет смешной комментарий. Если слово не подходит, ИИ с юмором объясняет почему, и игра заканчивается.

2. Правила игры
Игра начинается со слова «Камень» 🪨.
Игрок вводит слово или фразу, которая, по его мнению, побеждает текущее.
ИИ оценивает ответ:
подходит → слово становится текущим, счёт +1, показывается комментарий;
не подходит → ИИ смешно объясняет почему, игра окончена.
Слова не должны повторяться в рамках одной игры.
Цель: набрать как можно больше очков (рекорд сохраняется).


Один неверный ответ = конец игры? [x] да / [ ] нет (тогда: игра заканчивается  )
Строгость судьи: [ ] строгий / [x] средний / [ ] очень добрый
Допускаются шуточные и абсурдные ответы: [x] да / [ ] нет
3. Функциональные требования
3.1. Игровой экран
 Показ текущего слова с эмодзи крупным шрифтом
 Поле ввода и кнопка «OK» (отправка также по клавише Enter)
 Блок сообщения ИИ (комментарий, зелёный при успехе, красный при ошибке)
 Счёт текущей игры и рекорд
 История цепочки (🪨 Камень → 📄 Бумага → ...)
 Кнопка «Начать заново»
 Индикатор «ИИ думает...» во время запроса
3.2. ИИ-судья
 Определяет, побеждает ли слово игрока текущее слово
 Для каждого слова подбирает один стандартный эмодзи (Камень → 🪨)
 Пишет комментарий на русском языке с юмором (1–2 предложения)
 При неверном ответе обязательно объясняет, почему слово не подходит
 Отвечает строго в формате JSON (см. раздел 5)
3.3. Хранение данных
 Рекорд хранится в браузере (localStorage)
 Таблица рекордов для всех игроков (требует база данных)
3.4. Дополнительно:
 Звуки (правильный / неправильный ответ)
 Тёмная тема
 Выбор языка (русский / английский)
 Кнопка «Поделиться результатом»
 Ограничение по времени на ответ (неограничено)
 Выбор сложности / характера судьи (добрый, строгий, саркастичный)
 Адаптация под телефон
 Новые режимы (обновлениякаждую неделю)

5. Техническое решение

Стек: HTML + CSS + JavaScript (клиент), Node.js 18+ (сервер), Anthropic API (модель claude-haiku-5-5).

Структура проекта:

whatbeats/
├── index.html     # страница игры (интерфейс и логика)
├── server.js      # сервер: отдаёт страницу и обращается к ИИ
├── .env           # ключ ANTHROPIC_API_KEY (не публиковать!)
├── .gitignore     # должен содержать строку .env
└── README.md      # это ТЗ

API сервера: POST /api/judge

Запрос:

json
{ "current": "Камень", "guess": "Бумага" }

Ответ:

json
{ "beats": true, "emoji": "📄", "comment": "Бумага накрыла камень. Классика, но работает!" }

Ошибка: { "error": "текст ошибки" } (HTTP 500).


6. Запуск
Установить Node.js 18+ (node -v для проверки).
Получить API-ключ на console.anthropic.com.
Создать файл .env рядом с server.js:
   ANTHROPIC_API_KEY=ваш_ключ
В терминале VS Code выполнить: node server.js
Открыть в браузере: http://localhost:3000
7. Обработка особых случаев
Ситуация	Ожидаемое поведение 
Пустой ввод	Ничего не отправляется	
Повтор слова	Сообщение «Это слово уже было!», игра продолжается	
Ошибка API / нет интернета	Сообщение об ошибке, можно повторить	
ИИ вернул не JSON	Сообщение об ошибке, можно повторить	
Оскорбительное или неприличное слово	ИИ отшучивается и не засчитывает	
Попытка «обмана» (например, «всё побеждает»)	ИИ не засчитывает и шутит над этим	
8. Критерии приёмки
 Игра запускается командой node server.js без установки пакетов
 На старте показано «🪨 Камень»
 На слово «бумага» ИИ отвечает, что оно подходит, и показывает 📄
 На слово «банан» ИИ отвечает, что оно не подходит, и смешно объясняет почему
 У каждого слова в цепочке есть эмодзи
 Счёт растёт, рекорд сохраняется после перезагрузки страницы
 Ключ API нигде не виден в коде страницы
 Код читаемый, в index.html и server.js вместе не более ~250 строк
